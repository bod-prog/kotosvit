# Котосвіт

Затишний симулятор котячої цивілізації на маленькій планеті. Усе малюється в браузері, картинки не потрібні.

Мурко будує хату → Луна, кошенята Пух і Тінь, Сем і Віктор → Тарас ставить пірс. Далі рибки стають валютою: коти ловлять самі, а ти зводиш город, бібліотеку, маяк, обсерваторію й ратушу. З кожною будівлею приходить новий кіт.

## Пограти

Відкрийте `index.html` у браузері або увімкніть GitHub Pages:
Settings → Pages → Deploy from branch `main`.

- Крутіть планету пальцем.
- Торкніться кота — він замуркоче. Портрет унизу повертає камеру до нього.
- Прогрес лишається в цьому браузері. Кнопка ⟲ починає спочатку.

## Навіщо Grok Build

Не треба створювати гру з нуля в чаті.

1. Відкрийте цей репозиторій у Grok Build / дайте посилання: https://github.com/bod-prog/kotosvit
2. Пишіть: «Не переписуй з нуля. Візьми цей репо і додай лише [одна зміна]»
3. Перевіряйте диф. Якщо зламав візуал — відкатіть коміт.
